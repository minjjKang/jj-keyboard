# JJ Keyboard

한국어 두벌식과 영어 US QWERTY를 지원하는 오프라인 Android 입력기의 개발 버전 **0.4.0**입니다. Android 10(API 29) 이상을 대상으로 합니다. Galaxy Tab S9+(Android16)의 삼성 키보드를 참고해 배열·디자인·설정을 보강했습니다. 현재 기능과 기기 검증은 [0.4.0 기록](docs/verification-0.4.0-2026-11-05.md), 이전 과정은 [삼성 레퍼런스 관찰 기록](docs/samsung-reference-2026-11-05.md)을 참조합니다.

## 구현 범위

- 한글 초성·중성·종성 조합, 복합 모음·겹받침, 다음 음절로 받침 이동, 조합 입력 이력 역삭제
- 한/영 전환 및 시스템 subtype 전환, Shift·Caps Lock, Shift를 누른 채 문자 입력
- 숫자·기호 2개 페이지, 전화·숫자·날짜/시간 입력창 배치, 이메일·URL용 문장부호
- 공백·선택 영역 대체/삭제·반복 삭제, 입력창에서 요청한 검색·완료·다음 등의 Enter 동작
- ICU 문자 경계를 이용한 확정 문자 삭제(이모지·결합 문자 포함)
- 일반형·분할형, 분할 간격 조절과 양쪽 공백 키, 좁은/넓은 창별 높이·배치 저장, 시스템 테마
- 세로·가로 모드 저장과 툴바 전환, 넓은 창의 Del·양쪽 Shift·커서 키 확장 배열
- 보조 문자 길게 입력, 공백 키 스와이프 한영 전환·길게 누른 뒤 커서 이동
- 글자 크기·고대비·숫자 줄·툴바 설정, 길게 누르기 시간·삭제 속도 조절
- 선택형 공백 두 번 마침표, 문자 경계 단위 앞으로 삭제·커서 이동
- 동일 크기 문자 키, 스페이스바 언어 전환 화살표, 중복 내비게이션·입력 미리보기를 뺀 툴바
- 방향별 높이·너비 조절, 실제 자판의 드래그 핸들·미리보기·완료·취소·초기화
- 텍스트·이미지 클립보드 기록, 카드 붙여넣기·고정·삭제·일반 기록 비우기
- 백스페이스 좌우 슬라이드로 삭제·복원, Shift를 누른 채 왼쪽으로 밀어 단어 삭제, 진동·소리 설정
- 활성화 안내·입력기 선택·시험 입력란, 접근성 이름을 제공하는 실제 Button 기반 자판
- 개인별 터치 위치 보정, 한영 문맥 경계 보정, 툴바 단어 후보 선택과 즉시 되돌리기
- 한국어·영어 탭을 제공하는 집중 학습과 개인화 판정 지도, 키보드 위에 맞춘 가로 좌우 분할 배치
- 실제 키 배치별 터치 학습 프로필, 유사 배치의 약한 참고와 전체 학습 데이터 초기화

`INTERNET` 권한, 계정, 분석 SDK, 타이핑 기록이 없습니다. DataStore에는 설정만 저장하며, 복사한 텍스트·이미지 기록은 별도의 앱 전용 저장소에 보관합니다. 민감한 클립·비밀번호 입력 중 복사는 기록하지 않으며 저장을 끌 수 있습니다. 시험 입력란은 화면 상태 저장과 자동완성 대상에서도 제외합니다.

**설정 → 입력 옵션 → 터치 위치 개인화**에서 문맥 경계 보정과 툴바 단어 후보를 각각 켤 수 있습니다. 기본값은 꺼짐입니다. 후보를 선택한 직후 삭제 키를 누르면 이전 입력을 복원합니다. 앞 단어는 입력 세션 메모리에만 두며, 위치 학습을 켜면 터치 편차 집계를 기기에 보관합니다.

한영 단어 빈도 자원은 각각 12,000개이며, 짧은 예문으로 앞 단어와 다음 단어의 연결을 보완합니다. 자원 출처와 재생성 방법은 [사전 자료 안내](app/src/main/assets/language/NOTICE.md)에 있습니다.

같은 개인화 설정의 **집중 학습**은 부족한 키를 포함하는 내장 단어를 출제하고 검증된 표본만 저장합니다. 입력을 시작하면 설정 영역을 접고, 세로에서는 입력과 지도를 위아래로, 가로에서는 좌우로 배치해 키보드가 열린 상태에서도 함께 확인할 수 있습니다. 지도에서 키별 표본 수·평균 터치·공간 판정 영역을 확인합니다. 평소 입력 자동 학습이 꺼져 있어도 명시적으로 시작할 수 있으며, 수정·누락·모호한 단어는 제외합니다. 배치의 작은 조정은 같은 프로필을 사용하고 큰 변경은 별도 학습합니다. 입력 원문·개별 터치 순서는 저장하지 않으며, 이전 배치의 표본도 30일 유효기간과 보관 한도의 적용을 받습니다. 설계는 [구현 계획](docs/touch-personalization-training-plan-2026-11-08.md)을 참조합니다.

## 빌드

검증한 조합은 JDK 17, Gradle 8.13, Android Gradle Plugin 8.13.2, Kotlin 2.2.21, compile/target SDK 36입니다. 호환성이 확인된 버전을 고정했으며 최신 SDK 전환과 배포 정책 재확인은 후속 출시 작업입니다.

### 이 PC에서

프로젝트의 `.tools/`에 JDK·Gradle·Android SDK를 준비했습니다. 전역 환경변수 변경 없이 다음을 실행합니다.

```powershell
.\scripts\build.ps1
```

기본 작업은 `:hangul:test :touch:test :app:testDebugUnitTest :app:assembleDebug :app:lintDebug`입니다. 한글 엔진만 시험하려면 다음을 실행합니다.

```powershell
.\scripts\build.ps1 -Tasks ':hangul:test'
```

APK 위치: `app/build/outputs/apk/debug/app-debug.apk`

### 다른 개발 환경에서

Android Studio에서 이 폴더를 프로젝트로 열고 Gradle JDK 17, Android SDK Platform 36, Build Tools 35.0.0을 설정합니다. `local.properties`의 SDK 경로는 각 PC에서 생성하며 저장소에 포함하지 않습니다.

Windows용 선택적 준비 스크립트:

```powershell
.\scripts\bootstrap.ps1 -AndroidSdk
```

SDK 라이선스가 승인되지 않으면 패키지가 설치되지 않습니다. 약관 검토·동의 후 `.tools/android-sdk/cmdline-tools/latest/bin/sdkmanager.bat --licenses`를 실행하고 준비 스크립트를 다시 실행합니다. JDK와 Gradle 다운로드는 공급자가 공개한 SHA-256과 대조하고 Gradle Wrapper도 배포 ZIP의 체크섬을 고정했습니다.

macOS/Linux에서는 설치한 JDK·Android SDK와 함께 `sh gradlew :hangul:test :app:testDebugUnitTest :app:assembleDebug :app:lintDebug`를 사용합니다. 저장소의 Windows 전용 준비 스크립트는 사용하지 않습니다.

## 설치 및 사용

1. `app-debug.apk`를 Android 기기로 전송해 설치합니다. USB 디버깅 기기에서는 `adb install -r app/build/outputs/apk/debug/app-debug.apk`도 가능합니다.
2. **JJ Keyboard** 앱을 열어 **시스템 설정에서 활성화**를 선택합니다.
3. **JJ Keyboard 선택**에서 입력기를 선택하고 앱의 시험 입력란을 누릅니다.
4. `한/영`으로 언어, `!#1`로 숫자·기호 자판을 전환합니다. `1/2` 또는 `2/2`로 기호 페이지를 바꿉니다. 일반 배열에서는 왼쪽에, 확장 배열에서는 양쪽에 페이지 전환 키가 있습니다. Shift 두 번을 빠르게 누르면 Caps Lock입니다.
5. 공백 키를 빠르게 좌우로 밀면 한영 전환, 길게 누른 뒤 좌우로 움직이면 커서 이동입니다. 문자 키를 길게 누르면 오른쪽 위 보조 문자를 입력합니다. 쉼표 길게 누르기는 `!`, 마침표는 `?`입니다.
6. 상단 설정 키로 배치·크기·제스처·피드백을 바꾸고, 옆 모드 키로 일반/분할을 즉시 전환합니다. 입력기 선택과 닫기는 시스템 내비게이션 영역에서 조작합니다.
7. 클립보드 키는 기록 카드를 엽니다. 앱 설정의 글자 크기, 키 크기와 분할 간격, 키보드 모드, 레이아웃 화면 하단에서 자판을 미리 볼 수 있습니다. 키 크기 화면에서 핸들을 끌면 손을 뗄 때 자판이 새 크기로 바뀝니다. 분할 자판 미리보기를 켜면 가운데 간격을 확인할 수 있고, 완료를 누르면 크기와 간격이 저장됩니다.
8. 백스페이스를 왼쪽으로 밀면 여러 글자를 지우고 오른쪽으로 되돌리면 복원합니다. 다른 입력·커서 이동·입력창 변경 때 복원 기록을 끝냅니다.

분할 설정은 IME 폭 480dp 이상에서 적용되며, 600dp 이상은 넓은 화면 설정을 사용합니다. 가로 화면에서는 자판 높이를 제한합니다. 설정 화면의 시험 입력 내용은 앱이 다시 생성되면 사라집니다.

세로·가로 모드는 화면 방향별 설정을 우선 사용합니다. 폭840dp 이상에서는 Del·양쪽 Shift·별도 Enter·커서 키를 갖춘 확장 배열이 기본 적용됩니다. 설정의 레이아웃에서 확장 배열·보조 문자·숫자 줄을 끌 수 있습니다. 공백 두 번 마침표는 기본 꺼짐이며, 켜도 일반 영어 입력에서만 적용됩니다.

분할 간격은 설정에서 24~160dp로 조절할 수 있습니다. 좁은 창에서는 키 영역을 확보하도록 간격을 창 폭의 1/4 이하로 제한합니다. 양쪽 공백 키는 동일하게 현재 한글 조합을 확정하고 공백을 입력합니다.

## 연결 기기 테스트

실기기 검증은 iPlay60 mini Turbo (`7ce508a5`)에서 진행합니다. USB 디버깅을 허용하고 기기의 잠금을 직접 해제한 다음 실행합니다.

평소에는 변경한 동작과 영향을 받는 호출 경로를 검증합니다. `build.ps1 -Tasks`에는 관련 Gradle 작업만, `device-tests.ps1 -TestName`에는 관련 실기기 시나리오만 지정합니다. 문서만 바꾼 경우에는 문서의 링크와 명령 예시를 확인합니다. 전체 스위트는 릴리스 검증이나 영향 범위가 넓은 변경에 사용하고, 조합 중 가로·세로 전환과 연속 입력 검사는 해당 경로에 영향이 있을 때 실행합니다.

```powershell
.\scripts\device-tests.ps1 -DeviceSerial 7ce508a5 -TestName webInputTextareaAndContentEditable
```

스크립트는 개발 APK와 테스트 APK를 설치하고 실제 IME 창의 자판을 눌러 검증합니다. 기본 입력기를 일시적으로 JJ Keyboard로 선택하며, 종료 시 이전 입력기·화면 회전 설정을 복원합니다. 높이·분할·미리보기 등 시험 중 바꾼 앱 설정도 복원합니다. 앱을 제거하거나 앱 데이터를 지우지 않습니다.

로그와 자체 시험 화면은 `docs/device-runs/`에 저장됩니다. 캡처는 시험 앱이 표시되고 잠금이 해제된 경우에만 수행합니다. 테스트는 debug 소스의 로컬 EditText·WebView 입력란과 고정된 시험 문자열만 사용하며, 해당 Activity는 릴리스 APK에 포함되지 않습니다. `-TestName`에 메서드 이름을 쉼표로 구분해 여러 시나리오를 한 번에 실행할 수 있습니다. 전체 실기기 스위트가 필요할 때는 `-TestName`을 생략합니다.

## 구조

| 경로 | 역할 |
|---|---|
| `hangul/` | Android 의존성이 없는 조합 엔진·두벌식 매핑·Unicode 조합 계산 |
| `touch/` | 터치 위치 모델·오프라인 사전·문맥 점수 |
| `app/.../ime/` | IME 수명주기, 연결별 편집 세션, 입력창 프로필, 자판 상태 |
| `app/.../ui/` | 키 정의, 실제 View 크기에 맞춘 자판 배치, 터치·반복 삭제 |
| `app/.../settings/` | 설정 전용 DataStore, 활성화·설정·시험 화면 |
| `docs/` | 원본 계획, 자동 검증 기록, 실기기 시험표 |

한글 입력 정책: 쌍자음은 Shift로 입력하며, 초성의 같은 자음을 두 번 눌러 쌍자음으로 바꾸지 않습니다. 조합 중 삭제는 실제 입력 이력을 되돌리고, 확정한 음절은 글자 단위로 삭제합니다. 커서 이동·입력창 변경 때 기존 조합은 종료합니다. 연결이 바뀌거나 쓰기가 실패하면 이전 입력을 재전송하지 않습니다.

## 남은 작업

- Galaxy Fold·Tab 및 일반 휴대전화에서 실제 IME 크기·내비게이션 영역·접힘/회전 검증
- Samsung Internet·Chrome·카카오톡·Compose·WebView의 입력 세션 호환성
- TalkBack 터치 탐색·Shift 상태 읽기·반복 입력과 양손 다중 터치 실측
- 접힘 힌지 정보 연동(현재는 창 크기와 수동 분할 사용)
- release 입력 지연 측정과 장시간 실사용, 베타·릴리스 서명·배포 준비

천지인·음성·이모지 선택창은 후속 작업입니다. ICU의 문자 경계 판단은 Android 버전에 포함된 Unicode 데이터에 따릅니다. 주변 텍스트를 주지 않는 편집기나 조회 한도를 넘는 불명확한 클러스터에서는 확정 문자 삭제를 생략합니다.

참고: [Android IME 가이드](https://developer.android.com/develop/ui/views/touch-and-input/creating-input-method), [InputMethodService](https://developer.android.com/reference/android/inputmethodservice/InputMethodService), [AGP 8.13 호환성](https://developer.android.com/build/releases/agp-8-13-0-release-notes).
