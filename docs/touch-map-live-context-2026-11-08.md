# 개인화 지도 렌더링 최적화와 실시간 문맥 판정

2026-11-08. 지도 표시 지연을 줄이고 집중 학습에서 입력에 따른 문맥 판정 변화를 표시했다.

## 구현

- 배치·화면 크기·확대 영역이 같으면 픽셀별 기본 키와 이웃 후보를 재사용한다. 문맥만 바뀔 때 전체 화면의 키 탐색을 반복하지 않는다.
- 중심 보호 구역·무입력 영역은 기본 색을 재사용하고, 보정 가능 경계 픽셀만 다시 계산한다.
- 키별 공간 통계와 행 마스크를 미리 계산한다. 지도와 실제 터치는 같은 `SpatialResolver` 결정 함수를 사용한다.
- 초기 배치 계산은 문맥 갱신 작업과 분리하여 입력 때마다 취소·재시작되지 않게 했다. 같은 값의 갱신은 건너뛰고 진행 중에는 마지막 완성 화면을 유지한다. 오래된 계산 결과는 최신 화면을 덮어쓰지 않는다.
- 집중 학습 중에는 문맥 보정을 세션에 한해 활성화한다. 사용자의 전역 설정을 변경하지 않으며, 종료 후 원래 설정을 따른다.
- 실제 키보드에서 얻은 다음 26키의 문맥 점수를 지도에 전달한다. 문자·삭제·Shift·문맥 초기화·언어 자원 로드에 따른 현재 점수가 바뀌면 경계 색을 갱신한다.
- 입력 중 위치 보정은 실제 설정을 따르고, 단어 동안 고정된 공간 모델을 실제 터치와 지도에 동일하게 적용한다. 비활성 상태의 저장 프로필 지도는 기존 공간 모델 미리보기를 유지한다.
- 입력 문맥과 점수는 현재 연결의 메모리에만 존재한다. 연결 종료 시 지우며 원문·문맥 점수를 파일에 기록하지 않는다.

## 검증 결과

- `:touch:test` 19개와 `:app:testDebugUnitTest` 81개 통과.
- Debug 앱·실기기 테스트 APK 빌드 성공. Lint 오류 0개, 기존 영역 경고 11개.
- 일반/스플릿, 소수 배율, 확대·자르기, 공간/문맥 점수에서 각 픽셀을 실제 판정 결과와 비교했다. 기존 여백 색칠 정합성을 유지한다.
- 80 Turbo(iPlay80miniTurbo), Android 16/API 36에서 **5개 시나리오 통과**:
  - `liveContextMapReusesGeometryAndMatchesTapDecisions`
  - `guidedPracticeFitsAboveImeInBothOrientations`
  - `rapidInputDoesNotLoseOrDuplicateKeys`
  - `contextualTouchUsesPreviousWordWithoutChangingCenterTaps`
  - `spatialCorrectionIsOptInAndSkipsPasswordFields`

실제 `th` 입력 후 문맥 점수와 지도 렌더가 갱신되고, 배치 준비 횟수는 증가하지 않음을 확인했다. 실제 사전의 문맥 점수를 적용하면 기본 지도와 경계 색이 달라지며, 계산 결과는 실제 터치 판정과 픽셀 단위로 일치했다. 가로/세로·한국어/영어·일반/스플릿 화면과 40회 빠른 터치의 정확한 결과도 확인했다.
