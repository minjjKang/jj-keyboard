## 수정

- 기존 dp 좌표를 1/100 단위로 잘라 복원하던 방식을 제거했다. 측정 당시 화면 배율을 프로필에 저장하고 원래 정수 픽셀 경계와 여백 한계를 반올림해 복원한다. 배율이 없는 기존 저장 자료는 현재 기기 배율로 복원한다.
- 2dp 격자를 확대하던 방식 대신 표시되는 지도 픽셀의 중심마다 실제 `GeometrySnapshot`의 기본 키·여백·인접 키·공간 보정 함수를 호출한다.
- 결과 비트맵을 화면 픽셀에 1:1로 그려 확대 보간이나 격자 간격으로 생기던 빈 선을 없앴다. 자르기·축소·세로 정수 반올림에 따른 좌표 변환도 통일했다.
- 지도 터치로 키를 선택할 때도 같은 함수를 사용한다. 문자 키로 인식되는 여백은 색칠되고 선택된다. 분할 중앙·외곽·기능 키처럼 문자 키로 판정되지 않는 영역은 색칠하지 않는다.
- 지도는 기존과 같이 문맥 보정을 제외한 공간 판정 지도다. 키 테두리·문자·통계 점은 판정 색칠 위의 설명 요소다.
