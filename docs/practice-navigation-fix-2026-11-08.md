# 집중 학습의 언어 전환·커서 이동 수정 (2026-11-08)

후속 UI 변경: [완료 키로 제출·건너뛰기·종료 및 전체 삭제로 재입력](focused-practice-done-flow-2026-11-09.md). 아래 캡처의 화면 버튼은 이 후속 변경에서 제거했다.

## 원인

집중 학습은 예문과 연결할 수 있는 터치만 저장하도록 설계되어 있었지만, 언어 전환과 스페이스바 커서 이동까지 문장 전체의 제외 조건으로 처리했다. 언어 전환은 허용 명령에 없었고, 스페이스바 길게 누르기는 긴 누르기·커서 이동 양쪽에서 학습을 무효화했다. 언어만 다른 동일 키 배치도 일반 레이아웃 변경으로 판단했다.

기존 정렬은 끝에 입력하고 끝에서 삭제하는 순서를 기준으로 했으므로, 커서 이동을 단순 허용하면 중간 편집 후 터치를 잘못 연결할 수 있었다.

## 변경

- 집중 학습에서 한/영 버튼과 스페이스바 언어 전환을 허용한다. IME 전체의 subtype을 재시작하지 않고 현재 연습의 언어를 전환한다. 기존 입력과 예문은 유지하며, 다음 문장부터 선택한 언어로 출제한다. 현재 예문과 언어가 다르면 상태에 `다음 문장: 한국어/영어`를 표시한다.
- 스페이스바 길게 누르기와 커서 버튼을 허용한다. 커서 제스처는 공백 입력이나 학습 표본으로 기록하지 않는다.
- 현재 문장의 편집 결과를 실제 터치에 연결하는 메모리 내 추적을 추가했다. 중간 삽입·선택 교체·삭제 후에도 남아 있는 입력과 예문에서 유일하게 일치하는 터치만 저장한다. 한글의 받침 재결합처럼 한 번의 키 입력에서 여러 InputConnection 호출이 발생하는 경우를 함께 처리한다.
- 한글과 영문이 같은 물리 키 순서를 가져도 서로의 정답으로 인정하지 않는다. 검증한 터치는 해당 터치를 입력한 당시의 언어 프로필에 저장한다. 복수 프로필 저장 중 아직 저장하지 않은 프로필의 측정 배치가 사라지지 않도록 임시 프로필도 유지한다.
- 입력 승인 큐에서 다른 종류의 초기 selection 호출이 승인 항목을 잘못 소비하지 않도록 수정했다.
- 실제 레이아웃 변경·회전·다른 편집기 전환·초기화 후의 표본 제외는 유지한다. 문장과 터치 연결 정보는 연습 중 메모리에서만 사용하고, 문장 완료·중단 시 폐기한다. 저장 형식과 최근 100점 한도는 변경하지 않는다.

## 검증

실행 명령:

```powershell
.\scripts\build.ps1 -Tasks ':touch:test', ':app:testDebugUnitTest', ':app:assembleDebug', ':app:assembleDebugAndroidTest', ':app:lintDebug'
```

- touch JVM 35개 + app JVM/Robolectric 84개 = 119개 통과.
- Debug 앱/테스트 APK 빌드 성공. Android Lint 오류 0개, 기존 경고 11개.
- 새 테스트는 중간 편집의 터치 연결, 반복 문자 선택 교체, 한글 받침 재결합, 한글/영문 구별, 언어별 프로필 저장, 정상 언어·커서 명령 허용 및 실제 배치 변경 제외를 확인한다.
