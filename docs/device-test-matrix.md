# 실기기 시험표

실기기 검증 대상은 iPlay60 mini Turbo (`7ce508a5`, Android 14)입니다. Galaxy Tab S9+는 삼성 키보드 관찰용입니다. 0.4.0 빌드별 결과와 화면은 [실행 기록](verification-0.4.0-2026-11-05.md)에서 확인할 수 있습니다.

이 표에서 변경에 직접 관련된 항목과 영향을 받는 인접 동작만 골라 검증합니다. 실기기 실행은 `-TestName`으로 좁힙니다. 배치 변경은 세로·가로를 확인하고, 조합 중 가로·세로 전환과 연속 입력은 각각 회전·수명주기 또는 입력 처리량에 영향이 있을 때 실행합니다. 전체 스위트는 릴리스 검증이나 공통 입력 경로처럼 영향이 넓은 변경에 사용합니다.
