# 일반 한/영 자판의 숫자키·기능키 개인화

후속 변경: 반복 과제는 [문장형 집중 학습·최근 100점 분포](sentence-practice-adaptive-map-2026-11-08.md)로 교체했다. 아래는 해당 변경 이전의 검증 기록이다.

2026-11-08. 일반 한/영 자판에서 문자 26개에만 적용되던 터치 위치 학습·보정·집중 학습 지도를 숫자 행과 고정 기능키까지 확장했다.

## 적용 범위

- 일반 한/영 자판의 문자, 숫자 행 0–9, Shift·백스페이스·앞으로 삭제·공백·Enter·언어 전환·기호 전환·커서·설정·배치·클립보드 등 표시되는 고정 기능키를 대상으로 한다. 스플릿의 양쪽 공백/Shift와 툴바/하단 커서는 물리 키별로 구분한다.
- 기호 자판과 숫자/전화/날짜 전용 자판으로 학습을 확장하지 않는다. 특수문자·문장부호 연습과 자동 기호 페이지 전환을 제공하지 않는다. 일반 자판의 쉼표·마침표는 지도에 위치만 표시하며 개인화 대상에서 제외한다. 동적인 단어 후보와 빈 공간도 제외한다.
- 비밀번호와 `IME_FLAG_NO_PERSONALIZED_LEARNING` 필드는 학습·보정을 제외한다. 기존 이메일/URI/학습 제한 정책을 유지한다.

## 학습과 보정

- 실제 손가락의 짧은 탭만 사용한다. 문자키의 기존 단어 단위 검증을 유지하고, 숫자·기능키는 보정되지 않은 키 중앙 20% 이내의 확실한 탭을 낮은 가중치로 수집한다. 길게 누르기·반복 삭제·스와이프·커서/삭제 제스처·취소 입력을 새 표본으로 수집하지 않는다.
- 일반 표본 가중치 0.35, 검증한 집중 학습 표본 1을 유지한다. 인접 키 경계에서만 보정하고 중앙 입력을 보호하며, 보정 중심의 이동은 키 크기의 15% 이내로 제한한다.
- 기능키가 관련된 보정에는 양쪽 키에 각각 유효 표본 30개 이상이 필요하다. 문자 행 통계를 숫자나 기능키의 근거로 사용하지 않는다. 문맥 모델은 문자 입력에만 적용한다.
- 기능키 경계가 문자로 보정되어도 누르고 있던 Shift를 적용하고 사용한 것으로 처리한다. Shift를 놓은 뒤 다음 문자까지 대문자가 되는 것을 방지한다.

## 집중 학습과 지도

- 한국어/영어 탭, 레이아웃별 프로필, 세로 위아래/가로 좌우 42:58 배치를 유지한다. 키보드가 열린 상태에서 지도와 입력 영역을 스크롤 없이 확인할 수 있다. 별도 ‘학습 데이터 확인’ 페이지는 없다.
- 10회 연습에 일반 단어 4회, 숫자 입력 2회, 기능키 위치 연습 4회를 섞는다. 숫자 행이 꺼져 있으면 숫자 연습을 기능키 연습으로 대체해 현재 레이아웃을 유지한다.
- 기능키는 표본이 부족한 물리 키를 우선 선택하고, 표본 수가 같으면 백스페이스·Enter·공백·Shift 순으로 먼저 연습한다. 지정한 키를 5번 누른 뒤 ‘입력 완료’로 제출한다. 연습 중 실제 삭제·Enter·Shift 변경·언어/기호 전환·설정 이동·클립보드 열기 등은 실행하지 않고 위치만 확인한다. 물리 좌표가 없는 네이티브/접근성 클릭은 학습하지 않는다.
- 지도는 실제 측정한 문자·숫자·기능키 영역과 개인화 경계를 표시한다. 평균, 보정 중심, 현재 터치, 키별 일반/집중 표본 수를 확인할 수 있다. 숫자·기능키 터치도 즉시 갱신한다.

## 저장 호환성

- 기존 문자 ID 0..25를 유지하면서 숫자·기능키·중복 물리 키의 안정적인 ID를 추가했다. 32비트 문자 마스크를 키 ID 집합으로 대체했다.
- 실제 키 집합·위치·크기·간격·스플릿·방향·언어가 프로필 선택에 반영된다. 기호/전용 숫자 자판에서 이전 문자 프로필을 재사용하지 않는다.
- `touch-bias-v3`으로 저장하고 v1/v2 문자 통계도 읽는다. 기존 문자 전용 프로필은 보존하고, 측정 위치가 호환되는 새 프로필에 문자 통계만 약한 참고 근거로 사용할 수 있다.
- 최대 24개 저장 프로필, 키별 최대 8개 집계 버킷, 30일 만료, 원자적 파일 저장과 2MiB 한도를 유지한다. 원문·개별 터치 이력은 저장하지 않는다. 연습 좌표와 입력은 세션 메모리에서만 사용한다.
