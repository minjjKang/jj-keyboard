# 집중 학습 완료 키 중심 흐름 (2026-11-09)

## 동작

- 화면의 입력 완료·다시 입력·건너뛰기·연습 종료 버튼을 제거했다. 시작 전과 종료 후의 `집중 학습 시작`은 유지한다.
- 입력한 문장이 있으면 키보드의 완료 키로 제출하고 다음 예문으로 이동한다.
- 빈 문장에서 완료를 누르면 학습 없이 건너뛴다. 다음 예문에 `빈 상태에서 완료를 한 번 더 누르면 연습을 종료합니다` 안내를 표시한다.
- 빈 문장에서 완료를 연속 두 번 누르면 키보드를 닫고 `연습 종료` 및 저장·제외 결과를 표시한다. 글자를 입력하면 연속 건너뛰기 횟수를 초기화하며, 새 연습을 시작할 때도 초기화한다. 공백만 있는 문장은 빈 문장으로 취급하지 않는다.
- `입력을 확인할 수 없습니다` 상태에서는 입력 전체를 지우면 같은 예문으로 다시 입력할 수 있다. 이전 시도의 터치·편집 추적을 폐기하고 새 시도의 확인된 터치만 학습한다. 입력이 남아 있는 동안에는 기존 제외 상태를 유지한다.
- 빈 문장에서 누른 완료 키와 건너뛴 시도의 터치는 학습하지 않는다. 예문 완료 및 재입력 경계에서 기존 세대·프로필 검증은 유지한다.

화면에는 완료 키 동작 안내만 표시한다. 세로는 입력 위·지도 아래, 가로는 입력 왼쪽·지도 오른쪽 배치를 유지하며 버튼이 차지하던 공간을 줄였다.

- 기존 버튼을 누르던 기기 테스트는 실제 키보드 완료 키를 사용하도록 변경했다. 배치 검사는 제거된 네 버튼이 존재하지 않는지도 확인한다.
